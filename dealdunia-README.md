# DealDunia MLM Platform

> MLM web application and Android mobile app with referral-based growth architecture, marketing strategy, and API integration.

---

## Overview

DealDunia is a scalable Multi-Level Marketing (MLM) platform comprising a **web application** and **Android mobile application**. The project focuses on referral-based growth systems, user acquisition campaigns, and seamless cross-platform functionality through API integration.
